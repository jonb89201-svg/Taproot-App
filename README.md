# Taproot

**Open-source, non-custodial USDC payments for merchants who want self-custody.**

Taproot is a merchant console for accepting **USDC on Base** — non-custodial by design.
You own the contract and the funds. Taproot is software you run, not a payment
processor that can freeze your account or drop your category.

- **Non-custodial** — payments settle to *your* wallet; no middleman ever holds your money.
- **No chargebacks** — on-chain payments are final.
- **No deplatforming** — it's open-source software, not a service with a terms-of-service that can ban you.
- **Built on Base** — powered by the audited `PossessioPayments` contract.

Built for the merchants Stripe and PayPal call "high-risk" and refuse — starting with [Overgrow](https://overgrow.com).

## Run it
Single static page. Host on **GitHub Pages** (Settings → Pages → deploy from `main`, root),
or any static host. Open `index.html` locally in a wallet browser to try it.
